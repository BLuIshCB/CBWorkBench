## 🛠️ 核心开发原则与守则

* **单分支推进**：所有开发均在 `master` 分支上完成验证并提交，严禁随意切分多余分支。
* **服务启动**：后台为常驻进程，当前入口未开启自动热重载，代码修改后需重新启动以加载新代码。
* **交付规范**：任何功能改动完成，必须提供可点击的访问链接（如 `http://127.0.0.1:3721`）并保持测试套件 100% 绿灯。
